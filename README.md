# קליק פלוס

קליק פלוס היא אפליקציה פשוטה להפעלת פעולות לפי מספר כניסות רצופות לאפליקציה.

## איך זה עובד

כאשר מפעילים **עבודה שקטה ברקע**, המולטימדיה יכולה לפתוח את קליק פלוס בלי להציג את הממשק. כל כניסה לאפליקציה נספרת פעם אחת:

- כניסה אחת → פעולה 1
- שתי כניסות → פעולה 2
- שלוש כניסות → פעולה 3
- וכן הלאה עד 10 כניסות

אין צורך לבחור מקש, קוד מקש, ScanCode או התקן.

שירות הנגישות נשאר פעיל ברקע ומבצע את הפעולה שנבחרה. כאשר עבודה שקטה ברקע כבויה, פתיחת קליק פלוס פותחת את הממשק כרגיל.

## פעולות

אפשר לבחור פעולת מערכת או לפתוח אפליקציה. אפשר גם לבחור מצב שבו הפעולה תעבוד:

- בכל מצב
- אפליקציה מסוימת
- מוזיקה פועלת
- שמע מושתק
- הטלפון מצלצל
- רדיו פועל

## ממשק

הממשק נבנה מחדש בצורה פשוטה:

- מסך ראשי עם רשימת הפעולות
- הוספת פעולה במסך אחד
- 1–10 כניסות לבחירה
- הפעלה או כיבוי של כל פעולה
- מחיקה ועריכה
- מסך הגדרות קטן וברור
- פתיחת הגדרות נגישות מתוך האפליקציה

## Build

GitHub Actions builds the installable Release APK as the `ClickPlus-release-apk` artifact.
