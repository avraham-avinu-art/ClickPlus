# Click+

Click+ is a Kotlin Android hardware-key mapper using an AccessibilityService.

Core features from the supplied specification: onboarding, large-touch UI, OLED/light theme, floating HUD, multi-tap and confirmation mode, custom labels, per-mapping enable switches, debounce filtering, foreground keep-alive, boot receiver, app launch, system key, accessibility-node, and custom broadcast actions.

GitHub Actions builds and uploads `app-release.apk` on every push to `main`.
